MENU FILTER IMPLEMENTATION
==========================

Files:
- Logic: src/pages/MenuPage.tsx
- Styling: src/index.css


1. TRACKING THE SELECTED CATEGORY
---------------------------------

The page stores the currently selected menu category in React state:

  const [activeSection, setActiveSection] =
    useState("menu-promotions")

Each category button compares its section ID with this state:

  <button
    className={
      activeSection === category.id ? "is-active" : ""
    }
    aria-current={
      activeSection === category.id ? "true" : undefined
    }
  >

This applies the visual selected state and communicates the current
category to assistive technology.


2. DETERMINING WHICH SECTION IS VISIBLE
---------------------------------------

The page uses a fixed activation line:

  const activationLine =
    window.innerWidth <= 900 ? 175 : 220

Whenever the user scrolls, each menu section is checked against this
line:

  for (const section of sections) {
    if (
      section.getBoundingClientRect().top <= activationLine
    ) {
      currentSection = section.id
    } else {
      break
    }
  }

A category becomes active only after its section heading reaches:

- 220px from the top on desktop
- 175px from the top on tablet and mobile

This is more stable than activating a category as soon as any part of
its section enters the viewport.


3. HANDLING THE BOTTOM OF THE PAGE
----------------------------------

The Bites section may be too short to cross the activation line before
the page reaches its maximum scroll position.

The page checks whether the user has reached the bottom:

  const reachedPageEnd =
    window.innerHeight + window.scrollY >=
    document.documentElement.scrollHeight - 40

  if (reachedPageEnd && sections.length > 0) {
    currentSection = sections[sections.length - 1].id
  }

This ensures that Bites becomes active at the end of the page.


4. PREVENTING FLICKER DURING SMOOTH SCROLLING
---------------------------------------------

When a category is clicked, the page smoothly scrolls past other menu
sections. Without a temporary lock, those sections could briefly become
selected.

Two refs store the locked category and release timer:

  const lockedSection = useRef<string | null>(null)
  const unlockTimer = useRef<number | null>(null)

When a category is clicked:

  lockedSection.current = sectionId
  setActiveSection(sectionId)
  setSearchParams(
    { section: sectionId },
    { replace: true },
  )

While the category is locked, the scroll listener keeps it selected:

  if (lockedSection.current) {
    setActiveSection(lockedSection.current)
    return
  }

The lock is released after the smooth scrolling animation:

  unlockTimer.current = window.setTimeout(() => {
    lockedSection.current = null
    unlockTimer.current = null
  }, 850)


5. URL-BASED SECTION NAVIGATION
-------------------------------

Choosing a category updates the HashRouter URL:

  /#/menu?section=coffee

The Menu page reads the section query parameter:

  const requestedSection = searchParams.get("section")

It then finds and scrolls to the matching section:

  document
    .getElementById(requestedSection)
    ?.scrollIntoView({
      behavior: "smooth",
      block: "start",
    })

This makes individual menu categories directly linkable.


6. LISTENING FOR SCROLL AND RESIZE EVENTS
-----------------------------------------

The active-section calculation runs when the page scrolls or resizes:

  window.addEventListener(
    "scroll",
    updateActiveSection,
    { passive: true },
  )

  window.addEventListener(
    "resize",
    updateActiveSection,
  )

The event listeners and timeout are removed when the page unmounts:

  return () => {
    window.removeEventListener(
      "scroll",
      updateActiveSection,
    )

    window.removeEventListener(
      "resize",
      updateActiveSection,
    )

    if (unlockTimer.current) {
      window.clearTimeout(unlockTimer.current)
    }
  }


7. SELECTED CATEGORY STYLING
----------------------------

The selected filter is intentionally simple:

  .category-nav button.is-active {
    font-family: "Raleway:Bold", sans-serif;
    font-weight: 700;
    transform: none;
  }

The selected category uses bold text without a background, underline,
or pill shape.


SUMMARY
-------

The menu filter combines:

- React state for the active category
- Element positions for scroll tracking
- Different desktop and mobile activation lines
- A bottom-of-page fallback
- A temporary lock during smooth scrolling
- HashRouter query parameters for direct links
- Accessible aria-current states
- Simple bold selected styling
